# 音频文件说明

这个目录用于存放番茄钟应用的音效文件。

## 需要的音频文件

请将以下音频文件添加到这个目录中：

- `default.mp3` - 默认音效
- `bell.mp3` - 铃声（开始工作时播放）
- `chime.mp3` - 钟声（暂停时播放）
- `ding.mp3` - 叮声（重置时播放）
- `gong.mp3` - 锣声（长休息时播放）
- `notification.mp3` - 通知音效

## 音频文件要求

- 格式：MP3
- 时长：建议1-3秒
- 音量：适中，不要过于刺耳
- 文件大小：建议小于100KB

## 获取音频文件

您可以从以下来源获取音效：

1. 免费音效网站：
   - freesound.org
   - zapsplat.com
   - mixkit.co

2. 系统音效：
   - macOS: `/System/Library/Sounds/`
   - Windows: `C:\Windows\Media\`

3. 在线音效生成器：
   - tonegenerator.com
   - onlinetonegenerator.com

## 注意事项

- 确保音频文件没有版权问题
- 测试音频文件在不同设备上的播放效果
- 如果音频文件不存在，应用会使用系统默认音效作为备选
